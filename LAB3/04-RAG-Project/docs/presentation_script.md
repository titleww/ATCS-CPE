## เปิดเรื่อง (30 วินาที)

> "สวัสดีครับอาจารย์ ระบบที่ผมพัฒนาเป็น **Advanced RAG System** สำหรับถาม-ตอบข้อมูลดาราศาสตร์และการสำรวจอวกาศเป็นภาษาไทยครับ
>
> หลักการของ RAG คือ เราไม่ได้เทรนโมเดลใหม่ แต่เรา **ดึงข้อมูลที่เกี่ยวข้องจากคลังความรู้ของเรามาใส่ใน Prompt** แล้วให้ LLM อ่านข้อมูลนั้นแล้วเรียบเรียงคำตอบให้ ทำให้ LLM ตอบได้ถูกต้องตามข้อเท็จจริงที่เรามี ไม่มัวครับ
>
> ระบบของผมไม่ได้ใช้แค่ Dense Search อย่างเดียว แต่เป็น **Advanced RAG** ที่มีทั้ง Hybrid Search, Reranking, Query Transformation และ Memory ครบครับ ผมจะอธิบายตาม Flow ในสไลด์นี้เลยนะครับ"

📌 **เปิด GitHub**: ไฟล์ [`src/memory.py`](https://github.com/titleww/ATCS-CPE/blob/main/LAB3/04-RAG-Project/src/memory.py)

> "ไฟล์ `memory.py` มีคลาส `ConversationMemory` ครับ มันเก็บประวัติคำถาม-คำตอบไว้เป็น list แล้วมีฟังก์ชัน:

> - `forget_old_messages()` — ตัดประวัติเก่าทิ้งเมื่อเกินจำนวนรอบที่ตั้งไว้ แต่จะจำหัวข้อแรกสุดไว้กันหลุดประเด็นครับ"

## ขั้นที่ 3: Query Transformer — ปรับแต่งคำถามด้วย AI (1 นาที)

📌 **ชี้ที่ `rag_pipeline.py`** บรรทัด 55

> "ขั้นถัดมา ระบบจะปรับแต่งคำถามของผู้ใช้ก่อนเอาไปค้นหาครับ เพราะคำถามที่ผู้ใช้พิมพ์มาอาจจะสั้นเกินไป สะกดผิด หรือใช้คำไม่ตรงกับที่อยู่ในเอกสาร"

📌 **เปิด GitHub**: ไฟล์ [`src/query_transform.py`](https://github.com/titleww/ATCS-CPE/blob/main/LAB3/04-RAG-Project/src/query_transform.py)

> "ไฟล์ `query_transform.py` มีการปรับคำถาม 2 ระดับครับ:
>
> **ระดับที่ 1 — ไม่ใช้ AI** คือฟังก์ชัน `normalize_query()` ทำได้เร็วและฟรี ตัดคำลงท้ายที่ไม่ช่วยค้นหาออก เช่น 'ครับ', 'ค่ะ' และแทนคำแสลงด้วยคำทางการครับ
>
> **ระดับที่ 2 — ใช้ AI** คือฟังก์ชัน `transform()` ซึ่งมี 3 โหมดครับ:
> - **Rewrite** — ให้ LLM เขียนคำถามใหม่ให้ชัดเจนขึ้น โดยเฉพาะคำถามต่อเนื่องที่ต้องเติมบริบทจากประวัติ
> - **Multi-Query** — แตกคำถามเดียวเป็นหลายแบบที่ความหมายเดียวกัน แล้วค้นหาทุกแบบ เพื่อให้ครอบคลุมมากขึ้น
> - **HyDE** — ให้ LLM เขียนคำตอบสมมติขึ้นมาก่อน แล้วเอาคำตอบสมมตินั้นไปค้นหา เพราะคำตอบกับคำตอบจะมีเวกเตอร์ที่ใกล้กันมากกว่าคำถามกับคำตอบครับ"

## ขั้นที่ 4: Hybrid Search — ค้นหาแบบผสม (1 นาที)

📌 **ชี้ที่ส่วน Retrieval Stage บน Flowchart**

> "ขั้นนี้คือหัวใจของการดึงข้อมูลเลยครับ ระบบจะค้นหาพร้อมกัน 2 วิธี"

📌 **เปิด GitHub**: ไฟล์ [`src/hybrid_retriever.py`](https://github.com/titleww/ATCS-CPE/blob/main/LAB3/04-RAG-Project/src/hybrid_retriever.py) → ชี้ที่ฟังก์ชัน `retrieve()` บรรทัด 149

> "ฟังก์ชัน `retrieve()` จะยิงคำถามไปค้นหา 2 ที่พร้อมกันครับ:
>
> **วิธีที่ 1 — Dense Search** ผ่าน FAISS คือฟังก์ชัน `dense_search()` ที่แปลงคำถามเป็นเวกเตอร์ 384 มิติ แล้วหาเอกสารที่มีเวกเตอร์ใกล้เคียงที่สุด เหมาะกับการหาความหมายครับ"

📌 **เปิด GitHub**: ไฟล์ [`src/embedding_model.py`](https://github.com/titleww/ATCS-CPE/blob/main/LAB3/04-RAG-Project/src/embedding_model.py) (สั้นๆ)

> "ตัวแปลงเวกเตอร์ใช้โมเดล `paraphrase-multilingual-MiniLM-L12-v2` ครับ รองรับภาษาไทย มีการ normalize เวกเตอร์ให้ความยาวเท่ากับ 1 เพื่อให้ค่า Inner Product เท่ากับ Cosine Similarity ครับ"

📌 **กลับไปที่ `hybrid_retriever.py`** → ชี้ที่ `bm25_search()` บรรทัด 128

> "**วิธีที่ 2 — BM25 Search** คือค้นหาด้วยคำตรงตัวครับ เหมาะกับคำเฉพาะทาง เช่น ชื่อกล้องอวกาศ JWST หรือตัวเลขระยะทาง ที่เวกเตอร์อาจจะจับความหมายไม่ได้ ตรงนี้มีการตัดคำภาษาไทยด้วย PyThaiNLP ก่อนสร้าง index ครับ"

📌 **ชี้ที่ฟังก์ชัน `reciprocal_rank_fusion()`** บรรทัด 92

> "พอค้นได้ผลลัพธ์จากทั้ง 2 วิธีแล้ว ระบบจะรวมผลด้วย **Reciprocal Rank Fusion (RRF)** ครับ หลักการคือไม่ได้เอาคะแนนดิบมาบวกกัน เพราะคะแนน FAISS กับ BM25 มีสเกลต่างกัน แต่ใช้ **อันดับ** มาคำนวณแทน ด้วยสูตร 1 หาร (60 + อันดับ) แล้วรวมคะแนนจากทุกวิธีเข้าด้วยกัน เอกสารที่ถูกค้นเจอจากหลายวิธีก็จะได้คะแนนสูงขึ้นครับ"

## ขั้นที่ 5: Cross-Encoder Reranker — จัดอันดับใหม่ (30 วินาที)

📌 **ชี้ที่ `rag_pipeline.py`** บรรทัด 59–63 → แล้วเปิดไฟล์ [`src/rerankers.py`](https://github.com/titleww/ATCS-CPE/blob/main/LAB3/04-RAG-Project/src/rerankers.py) → ชี้ที่ `rerank()` บรรทัด 27

> "หลังจากรวมผลแล้ว ระบบจะส่งเอกสารที่เข้ารอบ 20 ชิ้นแรก ไปให้โมเดล **Cross-Encoder** จัดอันดับใหม่อีกครั้งครับ
>
> Cross-Encoder ต่างจาก Bi-Encoder ตรงที่มันจะอ่านคำถามกับเอกสาร **พร้อมกันเป็นคู่** แล้วให้คะแนนความเกี่ยวข้อง ทำให้แม่นยำกว่า แต่ก็ช้ากว่าด้วย เราจึงใช้มันกรองเฉพาะ 20 ชิ้นที่ผ่านรอบแรกมาแล้ว ไม่ได้ใช้กับทั้ง 38 ชิ้นครับ
>
> สุดท้ายเลือกเก็บแค่ **TOP 3** ชิ้นที่ดีที่สุดไปใช้ต่อครับ"

## ปิดเรื่อง — ผลการวัดประสิทธิภาพ (30 วินาที)

> "สุดท้ายครับ ผมได้ทำการวัดผลระบบด้วย Golden Set จำนวน 27 ข้อ ผลที่ได้คือ:
>
